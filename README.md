# 🚀 8-Day DSA Problem Solving Bootcamp

Welcome to the **8-Day DSA Problem Solving Bootcamp**!

This repository contains all the lecture notes, assignments, solutions, and resources used throughout the bootcamp.

Our goal is simple:

> **Learn how to think and solve problems, not just memorize solutions.**

---

# 📚 Problem Solving Framework

For **every problem**, follow this process.

```text
Read Problem
      │
      ▼
Understand Input & Output
      │
      ▼
Think Brute Force
      │
      ▼
Analyze Complexity
      │
      ▼
Find Better Approach
      │
      ▼
Identify Pattern
      │
      ▼
Write Code
      │
      ▼
Dry Run
      │
      ▼
Test Edge Cases
```

> **Never jump directly into coding.**
