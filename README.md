# 🚀 8-Day DSA Problem Solving Bootcamp

> **Learn to think like a problem solver, not just a programmer.**

This repository contains all the lecture notes, assignments, practice problems, and resources used during the **8-Day DSA Problem Solving Bootcamp**.

The goal of this bootcamp is **not to memorize solutions**, but to build strong problem-solving skills by recognizing patterns and choosing the right approach.

---

# 📌 Bootcamp Objective

By the end of this bootcamp, you should be able to:

- Understand a problem completely before coding.
- Think of a brute-force solution.
- Optimize the solution step by step.
- Analyze Time & Space Complexity.
- Identify common DSA patterns.
- Solve Easy and Medium level interview problems confidently.

---

# 📚 Problem Solving Framework

For **every problem**, follow this process.

```
Read Problem
      │
      ▼
Understand Input & Output
      │
      ▼
Think Brute Force
      │
      ▼
Analyze Complexity
      │
      ▼
Find Better Approach
      │
      ▼
Identify Pattern
      │
      ▼
Write Code
      │
      ▼
Dry Run
      │
      ▼
Test Edge Cases
```

Never jump directly into coding.

## ✅ Two Pointer

### Opposite Ends

```
L               R

1 2 3 4 5 6
```

Used for

- Pair Sum
- Palindrome
- Reverse Array

---

### Same Direction

```
Slow
Fast

↓

1 2 3 4 5
```

Used for

- Remove Elements
- Remove Duplicates
- Move Zeroes

```
Low
Mid
High

0 0 1 1 ? ? 2 2
```

Used for

# 📋 Rules During the Bootcamp

✅ Write clean and readable code.

# 🎯 Daily Learning Checklist

Before ending the day, make sure you can answer:

- What pattern did I learn today?
- Why does this pattern work?
- When should I use it?
- What is the brute-force solution?
- What is the optimized solution?
- What is the Time Complexity?
- Can I explain the solution without looking at the code?
