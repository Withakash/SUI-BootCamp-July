# Problem 1: Find Maximum Element

## Problem Statement

Given an array of integers, find the largest element.

### Input

```
5
2 7 1 8 4
```

### Output

```
8
```

### Constraints

- Use only one traversal.
- Do not sort the array.

# Problem 4: Reverse an Array

## Problem Statement

Given an array of integers, reverse the array **in-place**.

### Input

```
5
1 2 3 4 5
```

### Output

```
5 4 3 2 1
```

### Constraints

- Reverse using the Two Pointer technique.
- Do not create another array.

---

# Problem 5: Find the Second Largest Element

## Problem Statement

Given an array of integers, find the **second largest distinct element**.

If no second largest element exists, print:

```
Second Largest Does Not Exist
```

### Example 1

#### Input

```
5
8 3 10 1 6
```

#### Output

```
8
```

---

### Example 2

#### Input

```
4
5 5 5 5
```

#### Output

```
Second Largest Does Not Exist
```

### Constraints

- Do not sort the array.
- Try solving using only one traversal.
